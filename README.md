# K-Means Clustering from Scratch

این پروژه یک پیاده‌سازی ساده و آموزشی از بخش‌هایی از الگوریتم **K-Means Clustering** با استفاده از Python است.

## توضیح کوتاه

در این Notebook ابتدا داده‌های نمونه‌ی خوشه‌ای با `make_blobs` ساخته می‌شوند. سپس چند مرکز به‌صورت تصادفی انتخاب شده و فاصله‌ی اقلیدسی بین نقاط داده و مراکز محاسبه می‌شود.

در ادامه:
- فاصله‌ی مراکز از یکدیگر بررسی می‌شود تا مراکز بیش از حد به هم نزدیک نباشند.
- هر نقطه بر اساس نزدیک‌ترین مرکز به یک خوشه اختصاص داده می‌شود.
- برای هر خوشه یک رنگ انتخاب می‌شود.
- نقاط و مراکز خوشه‌ها با `matplotlib` نمایش داده می‌شوند.

## کتابخانه‌های استفاده‌شده

- `NumPy`
- `Matplotlib`
- `Scikit-learn`
- `random`

## توابع اصلی

- `generate_sample()` — ساخت داده‌های نمونه
- `distance()` — محاسبه فاصله اقلیدسی
- `check_centers()` — بررسی فاصله بین مراکز
- `choice_random_center()` — انتخاب مراکز تصادفی
- `create_distance_matrix()` — ساخت ماتریس فاصله و تعیین نزدیک‌ترین مرکز
- `generate_random_color()` — انتخاب رنگ برای خوشه‌ها

## هدف پروژه

هدف اصلی این فایل، تمرین مفاهیم پایه‌ی **Clustering، فاصله اقلیدسی، انتخاب مرکز و تخصیص نقاط به خوشه‌ها** و درک بهتر نحوه‌ی کار K-Means است.
